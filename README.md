# Free-GIF-Converter
Easily create GIFs under 20MB for Korean 'Naver Blog' users.

🔗 바로 사용하기: https://whymv.github.io/Free-GIF-Converter/

브라우저에서 실행되는 영상 → GIF 변환 도구입니다.

## 사용법
 
1. `입력` 버튼을 눌러서 변환할 동영상이 있는 폴더 경로 지정
2. `저장` 버튼 옆에 저장할 이름 입력
3. 해상도 및 재생속도 조절
4. `저장` 버튼 클릭

변환이 끝나면 지정한 이름의 zip 파일이 다운로드 폴더에 자동으로 저장됩니다.

## 지원 파일 형식
 
`.mov` `.mp4` `.m4v` `.avi` `.mkv`
