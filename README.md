# 🎞️ Free-GIF-Converter
Easily create GIFs under 20MB for Korean 'Naver Blog' users.

네이버 블로그 20MB 제한 때문에 화병나서 직접 만들었습니다.

🔗 바로 써보기: https://whymv.github.io/Free-GIF-Converter/

## 사용법
 
| 순서 | 할 일 |
|---|---|
| 1️⃣ | `입력` 버튼 → 변환할 동영상이 있는 폴더 선택 |
| 2️⃣ | `저장` 버튼 옆에 저장할 이름 입력 |
| 3️⃣ | 해상도 / 재생속도 취향껏 조절 |
| 4️⃣ | `저장` 버튼 클릭 → 끝 |

변환이 끝나면 지정한 이름의 zip 파일이 다운로드 폴더에 자동으로 저장됩니다.

## 지원 파일 형식
 
`.mov` `.mp4` `.m4v` `.avi` `.mkv`
